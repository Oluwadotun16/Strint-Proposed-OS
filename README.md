# Proposed-OS

Experimental OS project: Linux base, Android runtime, Wine, and a translation layer.

## Layout
- kernel/ - kernel config and patches
- android/ - Android runtime layer
- linux-runtime/ - Linux userspace base
- shell/ - desktop shell / UI
- wine/ - Windows compatibility
- translator/ - CPU/API translation
- graphics/ - GPU and display stack
- build/ - build system
- docs/ - documentation
- scripts/ - helper scripts
